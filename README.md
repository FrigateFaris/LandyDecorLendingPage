# Landy Decor — лендинг

Новогоднее оформление пространств в Ташкенте (часть Landy Group).

```
index.html      страница
css/decor.css   стили (12-колоночная сетка, клавиша G показывает колонки)
js/decor.js     анимации (GSAP + ScrollTrigger, Lenis), ролики, заявка
media/
  logo/         иконка сайта
  hero/         видео и заставка первого экрана (+ версии для телефона)
  works/        фото в ленте работ и плитки клиентов
  facade/       кино-сцена «Праздник видно с улицы»
  story/        глава «История»: первый венок, бант, видео Нигины
  clients/      галереи объектов по клиентам (thumbs/ — миниатюры)
```

Открывается как статический сайт: достаточно `index.html`, сборка не нужна.
Заявки уходят в Google Apps Script (адрес в `js/decor.js`).
